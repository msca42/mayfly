## 程序表象之下

- 层次结构图: 硬件、系统软件、应用软件
- 系统软件: 提供常用服务的软件，包括操作系统，编译器，加载程序和汇编程序
  - 操作系统
    - 用户程序和硬件之间的接口，为用户提供各种服务和监控功能
    - 作用
      - 处理基本的输入和输出
      - 分配外存和内存
      - 为多个应用程序提供共享计算机资源的服务
  - 编译器
    - 把高级语言编写的程序翻译成硬件能够执行的指令
- 从高级语言到硬件语言
  - 硬件使用电信号交流、电信号在计算机中的以指令的形式表示，指令就是能够被识别并执行的位串，也就是 0 和 1 组成的数字串
  - 使用数字表示指令和数据是计算机的基础
  - 最初程序员使用二进制数与计算机通信，二进制数称为机器语言
  - 之后发明了助记符和汇编程序，通过汇编器将助记符翻译成二进制指令，助记符称为汇编语言
  - 汇编语言和机器语言一一对应
  - 高级编程语言由单词和代数组成的最接近人类语言的计算机语言，通过编译器编译，有三种方式，一种是高级语言-汇编语言-机器语言（编译），一种是高级语言-中间代码-机器语言(编译、解释)， 一种是高级语言-机器语言（解释）

## 箱盖后的硬件
- 计算机是由完成输入、输出、处理和存储数据任务的5个部件构成
- 5 个部件: 输入、输出、存储器、运算器和控制器
- 显示器
  - 图像使用像素点构成，每个像素点使用三原色构成，三原色使用3x8bit一共24位的二进制数据表示
- CPU
  - 中央处理单元，由数据通路和控制器组成
  - 数据通路：负责算术运算
  - 控制器：负责指导数据通路、存储器和I/O设备按照程序指令正确执行
- 存储
  - 内存
    - 程序运行时的存储空间，由DRAM芯片组成
    - 存储程序的指令和数据
  - 高速缓存
    - 由SRAM芯片组成
- 指令系统体系结构
  - 定义了硬件和底层软件之间的接口
  - 包含编写正确运行机器语言程序所需的全部信息(指令集、寄存器组、存储访问方式和 I/O)
  - 应用二进制接口
    - 应用程序的基本指令系统和操作系统接口

## 性能

- 衡量性能的标准会根据不同的对象不同
- 常见标准
  - 响应时间: 执行时间、计算机完成某任务所需的总时间
  - 吞吐率: 带宽，单位时间内完成任务的数量
  - 个人设备更关注响应时间，服务器更关注吞吐率
  - 通常减少响应时间会伴随吞吐率的提高，而单纯提高吞吐率不会减少响应时间
- 时间分类
  - 响应时间、挂钟时间、运行时间: 完成任务总时间，包括硬盘访问，内存访问，I/O 操作，操作系统开销等一切时间
  - CPU 执行时间: 执行任务在 CPU 上花费的时间，不包括等待 I/O 或运行其他程序的时间
  - 用户 CPU 时间: 在程序本身所花费的 CPU 时间
  - 系统 CPU 时间: 执行程序花费在操作系统上的时间
  - 系统性能： 衡量空载系统的响应时间的基准
  - CPU性能：用户CPU时间
- 时钟周期
  - 由晶振产生的一种固定的时间间隔，用于同步CPU内部不同部件的指令执行操作
  - 时钟周期数: 处理器执行一条特定指令、一个程序段或整个程序所需的时钟周期的总数量
  - 时钟周期长度: 计算机处理器中一个时钟周期所持续的时间长度
  - 时钟频率：时钟周期长度的倒数
- 公式
  - 程序的 CPU 执行时间 = 程序的 CPU 时钟周期数 x 时钟周期长度
  - CPU 时钟周期数 = 程序的指令数 x 指令的平均时钟周期数 CPI
  - CPU 时间 = 指令数 x CPI x 时钟周期长度

## 功耗墙
- 目前集成电路的技术主要是CMOS，主要能耗来源于动态能耗
  - 晶体管在开关过程中产生的能耗
- 功耗墙的产生与主要是散热低于发热，从而导致硬件损坏
- 能耗：
  - 晶体管开关一次的能量
  - 1/2 x 负载电容 x 电压^2
- 功耗：
  - 单位时间的能耗
  - 1/2 x 负载电容 x 电压^2 x 开关频率

## 沧海巨变：从单处理器向多处理器转变
- 因为单核功耗墙问题，无法继续提高单核性能，通过增加多核，从而并行处理任务，增加总体性能，突破功耗限制
