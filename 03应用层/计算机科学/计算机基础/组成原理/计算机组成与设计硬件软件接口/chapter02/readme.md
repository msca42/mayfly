# 指令：计算机的语言

## 引言
- 指令集：一个给定的计算机体系结构所包含的指令集合
- 存储程序：多种类型的指令和数据均以数字形式存储于存储器中
- RISC-V
    - 操作数
        - 寄存器：快速定位数据，在寄存器中执行算术运算
        - 存储字：用于数据传输访问指令，主要将寄存器的内存中的数据相互传递
            - 存在基址地址和偏移量
    - 操作码
        - 算术运算、数据传输、逻辑运算、移位运算、条件分支、无条件跳转



## 计算机硬件的操作
- 算术运算通常由一个操作码和三个操作数组成，后两个操作数进行运算将结果赋给第一个操作数


    
## 计算机硬件的操作数
- 字：在通用情况下与操作系统的系统位数、寄存器大小一致，也就是64位
    - RISC-V中一般为32位
- 双字：字的双倍作为标准单位，用于较大的数据
    - RISC-V中一般为64位
- 寄存器
    - RISC-V中的寄存器数量通常32个，目的是减少对内存的访问
    - 变量在定义之后通常会存储在内存的存储单元中，在频繁使用时，会利用寄存器作为临时存储地址做加速处理
- 内存中的数据  
    - 对于复杂的数据结构，通常存储在内存中，而非寄存器中
    - 通过数据传输指令沟通内存和寄存器，指令提供内存地址，内存地址分为基址地址和偏移量
- 大端与小端(字节顺序)
    - 大端使用高位字节存储低地址
        - 网络传输中使用
    - 小端使用高位字节存储高地址
        - 本地使用
    - 主要影响多字节数据在内存中的存储顺序

## 有符号数与无符号数
- 任意基数，第i个数位d的值是 d x 基^i
- 原码：通过增加一个符号位表示二进制的正数和负数
    - 存在正零和负零
- 补码：前导0表示正数，前导1表示负数
    - 计算机中使用补码表示有符号数字

## 计算机中的指令表示
- 指令以一系列高低电平信号的形式保存在计算机中，并且以数字的形式表示，称为机器语言，这样的数字序列称为机器码
    - 指令长度根据架构不固定
- 指令字段
    - 由操作码，源寄存器，目的寄存器，立即数组成
    - 特性  
        - 指令长度分为固定长度和可变程度
        - 指令格式分为单一格式和多重格式
    - 通过组合不同的特性在硬件复杂度和执行效率之间找到最适合的方向

## 逻辑操作
- 移位：所有位都向左或向右移动
    - 分为逻辑移位和算术移位
- 按位操作
    - 分为与、或、取反、异或

## 用于决策的指令
- 在编程语言层面上使用if、goto等语言决策
- 在指令层面称为条件分支指令
- 基本块：指令序列，该序列没有分支
